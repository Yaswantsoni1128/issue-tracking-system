# Issue Tracking System

A full-stack web application developed using Java Spring Boot and MySQL that enables users to report, manage, and track issues through a centralized platform.

## Features
- Authentication Module (JWT-based, Admin/User roles)
- Issue Management (Create, Update, Delete, View, Filter)
- Issue Status Tracking (Pending, In Progress, Resolved)
- Admin Dashboard
- User Features

## Tech Stack
- Backend: Java 17, Spring Boot, MySQL, Spring Security, JWT, JPA/Hibernate
- Frontend: React.js, Tailwind CSS, Axios
